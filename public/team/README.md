# Team-Fotos

Lege hier echte Fotos ab, benannt nach dem `slug` in `src/data/team.js`,
z. B. `ismet.jpg`, `hilke-tambke.jpg`. Empfohlen: quadratisch, 1024×1024 px, JPG < 150 KB.

Fehlt ein Foto, erzeugt die Seite automatisch eine Platzhalter-Textur
(Initialen auf Creme) – die Seite bleibt also immer lauffähig.
